# ScreenWisp brand assets

The approved S-shaped disappearing stroke preserves the reference silhouette and purple fading trail. Midtones and a fine cool-lilac edge improve contrast on light/dark surfaces without a background plate. Original reference uploads remain local and are excluded from the public source set.

- `ScreenWisp.ico`: transparent 32-bit PNG frames at 16, 20, 24, 32, 48, 64, 128 and 256 px.
- `ScreenWisp-tray.ico`: dedicated 16, 20, 24 and 32 px subset.
- `ScreenWisp-mark.svg`: scalable master.
- `png/ScreenWisp-{size}.png`: transparent exports, including 1024 px.
- `ScreenWisp-social-preview.svg` and `.png`: 1280×640 GitHub cover using the approved logo. This is branding, not a UI or input demonstration.
- `../tools/GenerateIcon.ps1` and `GenerateSocialPreview.ps1`: reproducible native rendering, no image generation service required.

Micro sizes 16–24 use simplified contour geometry, a contrast edge and 1/2/3 trailing particles. Larger frames preserve four particles and tapered tips. Each frame is vector-rendered rather than reduced from a large raster. Application icon resources remain byte-identical to the approved ICO; this presentation task does not replace them.
